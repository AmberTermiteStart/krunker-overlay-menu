## 🧩 About

**Krunker Overlay Menu** is a curated list of Krunker open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, spawn marker
- **Quality-of-Life Helpers** — class catalog, loadout notes, overlay configuration
- **Research Notes** — movement layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Match Helpers
- Spawn Marker — track respawn points in practice lobbies
- Show Hitboxes — visualize player and obstacle hitboxes
- Replay Notes — record and review movement runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Loadouts
- Class Catalog — browse classes, skins, and weapon finishes
- Custom Loadout Notes — organize player cosmetics
- Crosshair Notes — improved crosshair visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Movement Notes — study strafing and bunny-hop timing
- Jump Buffer Notes — chain complex maneuvers in the editor
